# 版式抽卡机（LotGo 机制复刻）

对小红书上 LotGo v1.10「版式抽卡机」的机制拆解 + 一个能跑的最小复刻。
零依赖，直接用浏览器打开 `index.html` 即可。

- **机制拆解全文 → [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)**
- 核心一句话：`(参数, 种子) ──纯函数──> 元素列表 ──> DOM`，点一次换一个种子。

## 能干什么

- **连抽 12 张挑一张** — 一次生成一屏缩略图，点中哪张就放大哪张
- **填自己的文案** — 大标题 / 小标题 / 正文，留空就用内置文案池；用 `|` 分隔多条，抽卡时随机取
- **导出 PNG** — 1 倍或 2 倍高清。canvas 重绘同一份元素列表，不是截图，所以任意倍率都清晰
- **五种尺寸** — 3:4 小红书 / 2:3 海报 / 1:1 方图 / A4 打印 / 9:16 手机
- **收藏** — 抽到好的存下来（种子 + 当时全部参数），随时一键还原
- **载入自己的照片** — 替掉程序化占位图

## 用法

```
open index.html          # 或者 python3 -m http.server 后访问
```

- **空格 / 点 LotGO 按钮** — 抽一张
- **G** 连抽 12 张 · **F** 收藏 · **E** 导出 2 倍图
- **← →** — 上一张 / 下一张（存的是种子，所以精确复现）
- **风格预设** — 单击套用；**Shift+单击**加入混抽池，抽卡时在池里随机命中一个
- **保存为预设** — 把当前整个面板状态存进 localStorage
- **载入图片** — 用自己的照片替换程序化生成的占位图

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面骨架 + 控制面板 |
| `src/engine.js` | 引擎：种子随机、版式母题、字号反解、避让、DOM 渲染 |
| `src/canvas.js` | canvas 渲染器，用于任意倍率导出（跟 DOM 版画同一份元素列表）|
| `src/ui.js` | 面板绑定、抽卡历史、预设存取 |
