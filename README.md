# 抽屉视觉

对小红书上 LotGo v1.10「版式抽卡机」的机制拆解 + 一个能跑的最小复刻。
零依赖，直接用浏览器打开 `index.html` 即可。

- **机制拆解全文 → [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)**
- 核心一句话：`(参数, 种子) ──纯函数──> 元素列表 ──> DOM`，点一次换一个种子。

## 能干什么

- **连抽 12 张挑一张** — 一次生成一屏缩略图，点中哪张就放大哪张
- **填自己的文案** — 大标题 / 小标题 / 正文，留空就用内置文案池；用 `|` 分隔多条，抽卡时随机取
- **导出 PNG** — 1 倍或 2 倍高清。canvas 重绘同一份元素列表，不是截图，所以任意倍率都清晰
- **五种尺寸** — 3:4 小红书 / 2:3 海报 / 1:1 方图 / A4 打印 / 9:16 手机
- **锁定重抽** — 配色 / 字体 / 版式 / 文案，锁住喜欢的那部分，只重抽其余
- **收藏** — 抽到好的存下来（种子 + 当时全部参数），随时一键还原
- **载入自己的照片** — 替掉程序化占位图

## 用法

```
open index.html          # 或者 python3 -m http.server 后访问
```

- **空格 / 点 LotGO 按钮** — 抽一张
- **G** 连抽 12 张 · **F** 收藏 · **E** 导出 2 倍图
- **← →** — 上一张 / 下一张（存的是种子，所以精确复现）
- **风格预设** — 单击套用；**Shift+单击**加入混抽池，抽卡时在池里随机命中一个
- **保存为预设** — 把当前整个面板状态存进 localStorage
- **载入图片** — 用自己的照片替换程序化生成的占位图

## 面板

默认只露出四样东西：**抽卡区**（抽 / 翻页 / 连抽 / 收藏 / 导出 / 尺寸）、**文案**、**风格**、
以及一条折起来的「细调」。图层、调色、网格、标题组那些低频参数全在折叠区里，需要时再展开。

原来照着截图抄过来的「卡片模式」和「AI分层」已删——引擎里 0 次调用，点了不会有任何变化。

## 部署

```
node build.js        # 生成 dist/index.html
```

`dist/index.html` 是**单文件、零外部依赖**（62 KB），三个 js 全部内联。
上传到任何静态服务器的任意目录即可，不需要构建环境、不需要服务端。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面骨架 + 控制面板 |
| `src/engine.js` | 引擎：种子随机、版式母题、字号反解、避让、DOM 渲染 |
| `src/canvas.js` | canvas 渲染器，用于任意倍率导出（跟 DOM 版画同一份元素列表）|
| `src/ui.js` | 面板绑定、抽卡历史、预设存取 |
| `build.js` | 打包成 `dist/index.html` 单文件 |

## 其他单页动效

仓库里另有几个独立的动效练习，每个都是**一个 HTML、零依赖**，浏览器直接打开即可（`file://` 也行），
不经过 `build.js`，直接上传即可。

| 文件 | 名字 | 一句话 |
|---|---|---|
| `feeder.html` | 出片机 | 黄熠的作品集首屏：一台金属小机器（Blender 渲染）把 yihuang.art 的作品页一张张匀速吐出来，滚轮快进倒带、拖纸、悬停放慢；作品名依次虚化轮换。交接文档见 [docs/FEEDER.md](docs/FEEDER.md) |
| `tape.html` | 滚滚胶带 | 拖着一卷胶带在地面上走，走到哪印到哪，带子上不断长出新图案 |
| `sand.html` | 沙画 | 在沙子上写字：高度场 + 光照，不是粒子 |
| `bouquet.html` | 花束 | 抽卡式生成花束，所有花茎从同一个扎点沿圆锥面散开 |
| `fracture.html` | 撕裂 | 把字撕开，断口拉出一层薄膜 |
| `letter.html` | 书之痕 | 一封信被敲碎，字重新流进每一块碎片 |

页面里不用任何参考视频里的真人、真品牌。出片机是仓库主人黄熠自己的首屏（纸上是 yihuang.art 的作品页），底部注明「动效复刻练习」。
