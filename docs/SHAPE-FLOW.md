# 形状排版拆解

对小红书「氧化还原工作室 typowow」那支海报编辑器演示的机制拆解 + 最小复刻。
成品：[`poster.html`](../poster.html)，零依赖，浏览器直接打开。

## 一句话

普通排版里，**每行可用宽度是个常数**；这套东西里，**它是行号的函数**。

```
              普通段落                      形状排版
        ┌──────────────────┐         ┌──────────────────┐
        │████████████████  │         │      ████        │
        │████████████████  │         │   ██████████     │
        │████████████████  │         │ ██████████████   │
        │████████████████  │         │   ██████████     │
        │█████████         │         │      ████        │
        └──────────────────┘         └──────────────────┘
          width = const                width = f(y)
```

断行算法本身没变，还是最土的贪心：塞词，塞不下就换行。
唯一的改动是每行开始前多问一句"**我这行有多宽**"。

## 三个部件

### 1. 宽度包络 `shape(t) -> [x0, x1]`

`t` 是行在块内的进度 0→1，返回值是左右边界占块宽的比例。
全部形状都塞在 `SHAPES` 里，加新版式就是加一个函数，别处一行都不用动：

| 名字 | 轮廓 | 做法 |
|---|---|---|
| 透镜 | 中间胖两头尖 | `sin(πt)` |
| 楔形 / 倒楔 | 摊开 / 收口 | 线性 |
| 沙漏 | 两头宽中间掐细 | `\|cos(πt)\|` |
| 波形 | 左边界荡秋千 | 左边界 `sin`，宽度恒定 |
| 河道 | 平滑随机游走 | 两个不同频率的 `sin` 叠加 |
| 直栏 | —— | 对照组，就是普通段落 |

### 2. 高频抖动

只有包络线的话，段落边缘是一条**光滑曲边**，一眼就假。
参考视频里那种撕纸一样的毛边，来自叠在包络上的逐行噪声：

```js
a += (jit(r, phase) - .5) * jitter;   // 左边界
b += (jit(r, phase + 3.1) - .5) * jitter;
```

`jit()` 是 `sin(r * 12.9898) * 43758.5453` 取小数部分——经典的 shader 哈希，
无状态、只跟行号有关，所以重排时同一行永远抖到同一个位置。

### 3. 溢出规则

当某行分到的宽度**比下一个词还窄**时，让这个词自己占一行，并且贴块的左边缘。

这条规则是整个效果里最出戏的一笔：参考视频里那些突然甩到最左边、孤零零
一个单词的行（`conversation` / `profound` / `floribunda,`），全是它干的。
没有这条，形状再花也只是"排得整齐的花瓶"，缺那股野劲。

## 交互

视频里没有任何控制面板，全靠直接操作，所以这里也没有：

| 操作 | 结果 |
|---|---|
| 拖动块 | 移动 |
| 拖右下角 | 改尺寸；**字号跟着块宽等比走** |
| 单击块 | 换下一个形状 |
| 空格 | 换种子，整页重排 |
| C | 清掉墨迹 |

"拉宽 → 字变大"是视频里最有说服力的一下：一条看不清的细毛边，拉开就变成
能读的段落。实现只是 `fs = fs0 * (w / w0)`，但手感对了。

## 没做的部分

- **字体**：参考用的是真·超窄黑体（Druk / Anton 一路）。这里不引外部资源，
  用 `scaleX` 把系统黑体压扁顶上，压缩比取「固定值」和「最长一行刚好不出血」
  里更小的那个，所以任何字体回退下都不会溢出，但字面细节不如真字体。
- **照片**：程序化生成的花园占位图（色块 + 花瓣 + 颗粒 + 软边人影），不引用原图。
- **导出**：没做。要出图先用浏览器截屏。
